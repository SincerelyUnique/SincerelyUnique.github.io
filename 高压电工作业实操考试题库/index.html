# 科目一：安全用具使用

# 试题： K11-01

# 考试说明

  • 考试时间：30 分
  • 分值：100 分（80 分合格）
  • 任务：
    • 登杆
    • 万用表（数字）测电压（交流 / 直流）
    • 兆欧表测 10kV 电缆绝缘电阻（>1000M 欧）

# 考试内容

  1. 登杆作业
    1. 选：鞋、帽、服、脚扣、安全带、围杆带、安全绳 （不合格项：任一未选 / 选错不合格）
    2. 穿：鞋、帽、服、带
    3. 设 - 围栏，挂 - 牌，说 - 监护人已到位
    4. 查：线路名称、杆号、杆根、拉线
    5. 冲击试验：围杆带、安全绳、脚扣
    6. 登杆：>2m (不合格项：高度不够、未正确穿戴脚扣和围杆带、滑落到底、跌落、脚扣脱落、脱离围杆、用手抱柱、安全带未闭锁)
  2. 其他安全用具选用
    1. 选：手套 (不合格项：未选 / 选错)
    2. 选：绝缘靴 (不合格项：未选 / 选错)
  3. 仪表选用
    1. 选数字式万用表测电压 （不合格项：未选 / 选错、挡位错、测量时更换挡位）
      1. 选：数字万用表
      2. 查：外观、合格证、有效期、端子接口、线皮、旋转无卡顿、最终处于 off 档或交流电压最大档
      3. 验：调至蜂鸣档，短接测试
      4. 测：合闸状态测试，交流 - 不区分正负极，直流 - 区分正负极，调制对应最大档，依据测量值依次调小
      5. 记：记录交流（或直流）电压、量程、最终测量值
    2. 选择兆欧表测 10kV 电缆绝缘电阻 （不合格项：未选 / 选错、未按要求测量）
      1. 选：兆欧表（量程大于 1000 兆欧）、放电棒、高压验电器、工频信号发生器、绝缘靴、绝缘手套、安全帽、短接线
      2. 说：口述断电、三相验电、放电棒接地、口述放电 5 分钟（组放 + 直放）
      3. 短接线夹子先接地，另外三个夹子再分别夹住电缆 3 相铜片
      4. 取兆欧表，E 端接地，中间接线缠绕电缆 a 相绝缘皮，兆欧表 L 端夹住 a 相铜片，去掉 a 相短接线夹子，
      5. 口述摇表 1 分钟 120 转，测试电阻大于 1000 兆欧，符合绝缘标准，a 相放电
      6. 依次测试 b 相、c 相，测试后放电
      7. 测试结果如均大于 1000 兆欧，测试合格，否则绝缘不合格
      8. 记录三相铜线与绝缘皮之间测量电阻，最低电阻 > 1000 兆欧合格，并整理工机具
  4. 识别电气安全标示：禁止、指令、警告、提示四类，每类随机选一
  5. 整理场地

# 试题： K11-02

# 考试说明

  • 考试时间：30 分
  • 分值：100 分（80 分合格）
  • 任务：
    • 登杆
    • 万用表测电阻
    • 钳形电流表测交流电

# 考试内容

  1. 登杆作业
    1. 选：鞋、帽、服、脚扣、安全带、围杆带、安全绳 （不合格项：任一未选 / 选错不合格）
    2. 穿：鞋、帽、服、带
    3. 设 - 围栏，挂 - 牌，说 - 监护人已到位
    4. 查：线路名称、杆号、杆根、拉线
    5. 冲击试验：围杆带、安全绳、脚扣
    6. 登杆：>2m (不合格项：高度不够、未正确穿戴脚扣和围杆带、滑落到底、跌落、脚扣脱落、脱离围杆、用手抱柱、安全带未闭锁)
  2. 其他安全用具选用
    1. 选：合格的高压验电器、使用高压验电器（戴手套） (不合格项：未选 / 选错)
    2. 选：携带型高压短路接地线 (不合格项：未选 / 选错)
  3. 仪表选用
    1. 选数字式万用表测电阻 0-100k 欧 （不合格项：未选 / 选错、挡位错、未断电测量）
      1. 选：数字万用表
      2. 查：外观、合格证、有效期、端子接口、线皮、旋转无卡顿、最终处于 off 档或交流电压最大档
      3. 验：调至蜂鸣档，短接测试
      4. 测：分闸状态测试，调至电阻对应最大档 20M 欧，依据测量值依次调小
      5. 记：记录量程与最终测量值
    2. 选数字式钳形电流表测交流电流 0-3000mA （不合格项：未选 / 选错、档位选错、带负载更换档位）
      1. 选：钳形电流表
      2. 查：检查外观、合格证、有效期、旋转是否卡顿、默认调至最大档
      3. 测：合闸状态测试，每次测完需拿开，调整档位且夹头接触消磁后再次测量
      4. 记：记录量程与最终测量值
  4. 识别电气安全标示：禁止、指令、警告、提示四类，每类随机选一
  5. 整理场地

# 试题： K11-03

# 考试说明

  • 考试时间：30 分
  • 分值：100 分（80 分合格）
  • 任务：
    • 登杆
    • 钳形电流表测交流电
    • 兆欧表测三相电机相间绝缘电阻（>500 欧）

# 考试内容

  1. 登杆作业
    1. 选：鞋、帽、服、脚扣、安全带、围杆带、安全绳 （不合格项：任一未选 / 选错不合格）
    2. 穿：鞋、帽、服、带
    3. 设 - 围栏，挂 - 牌，说 - 监护人已到位
    4. 查：线路名称、杆号、杆根、拉线
    5. 冲击试验：围杆带、安全绳、脚扣
    6. 登杆：>2m (不合格项：高度不够、未正确穿戴脚扣和围杆带、滑落到底、跌落、脚扣脱落、脱离围杆、用手抱柱、安全带未闭锁)
  2. 其他安全用具选用
    1. 选：手套 (不合格项：未选 / 选错)
    2. 选：绝缘梯 (不合格项：未选 / 选错)
  3. 仪表选用
    1. 选数字式钳形电流表测交流电流 0-3000mA （不合格项：未选 / 选错、档位选错、带负载更换档位）
      1. 选：钳形电流表
      2. 查：检查外观、合格证、有效期、旋转是否卡顿、默认调至最大档
      3. 测：合闸状态测试，每次测完需拿开，调整档位且夹头接触消磁后再次测量
      4. 记：记录量程与最终测量值
    2. 选择兆欧表测测 380V 三相电机相间绝缘电阻 （不合格项：未选 / 选错、未按要求测量）
      1. 选：兆欧表（量程大于等于 500 欧）、绝缘靴、绝缘手套、安全帽
      2. 验：外观、合格证、有效期、短接蜂鸣测试、归 off 档
      3. 说：口述断电、三相验电、放电
      4. 测：每两相间做绝缘电阻测试、做完放电
      5. 记：记录 3 组电阻数据，均大于 500 欧姆，测试合格，否则不合格
  4. 识别电气安全标示：禁止、指令、警告、提示四类，每类随机选一
  5. 整理场地

# 试题： K11-04

# 考试说明

  • 考试时间：30 分
  • 分值：100 分（80 分合格）
  • 任务：
    • 登杆
    • 指针万用表测电压（交流 / 直流）
    • 接地电阻测试仪测保护接地电阻（<=4 欧）

# 考试内容

  1. 登杆作业
    1. 选：鞋、帽、服、脚扣、安全带、围杆带、安全绳 （不合格项：任一未选 / 选错不合格）
    2. 穿：鞋、帽、服、带
    3. 设 - 围栏，挂 - 牌，说 - 监护人已到位
    4. 查：线路名称、杆号、杆根、拉线
    5. 冲击试验：围杆带、安全绳、脚扣
    6. 登杆：>2m (不合格项：高度不够、未正确穿戴脚扣和围杆带、滑落到底、跌落、脚扣脱落、脱离围杆、用手抱柱、安全带未闭锁)
  2. 其他安全用具选用
    1. 选：选防护眼镜并按规范穿戴 (不合格项：未选 / 选错)
    2. 选：绝缘垫 (不合格项：未选 / 选错)
  3. 仪表选用
    1. 选指针式万用表测电压 （不合格项：未选 / 选错、挡位错、测量时更换挡位）
      1. 选：合格的指针万用表
      2. 查：外观、合格证、有效期、端子接口、线皮、旋转无卡顿、最终处于交流电最大档
      3. 验：调至蜂鸣档，短接测试
      4. 测：合闸状态测试，交流 - 不区分正负极，直流 - 区分正负极，调制对应最大档，依据测量值依次调小
      5. 记：记录量程和最终测量值（注意看指针量程）
    2. 选择接地电阻测试仪 （不合格项：未选 / 选错）
      1. 选：接地电阻测试仪
      2. 验：外观、合格证、有效期、线皮、旋转是否卡顿，在 off 档
      3. 说：口述断电、三相验电、放电
      4. 夹：5 米 E 接地线夹、中间 20 米 P 电位极夹、40 米 C 电流极夹
      5. 测：选最大档 200 欧档、按住左侧按钮不动、数值稳定后右旋锁定，若电阻很低、依次调小量程重新测量
      6. 记：归至 off 档记录量程和数值，<=4 欧姆接地良好
  4. 识别电气安全标示：禁止、指令、警告、提示四类，每类随机选一
  5. 整理场地

# 科目二：作业现场安全隐患排除

# 试题： K21-01

# 考试说明

  • 考试时间：10 分
  • 分值：100 分（80 分合格）
  • 任务：辨识开关柜停（送）电作业风险隐患、辨识柱上变压器停（送）电作业风险隐患

# 考试内容

  1. 考前准备：穿戴安全帽、工作服、绝缘靴 （不合格项：任意一项未穿戴或未按规范穿戴）
  2. 作业现场风险隐患辨识
    1. 辨识开关柜停（送）电作业风险隐患
      • 接地刀闸处于合闸状态下操作手车
      • 操作无监护人
      • 作业人员未正确穿工作服
      • 作业人员未正确戴安全帽
    2. 辨识柱上变压器停（送）电作业风险隐患
      • 作业人员未正确戴护目镜
      • 作业人员未正确穿绝缘手套
      • 作业人员未正确穿绝缘靴
      • 停（送）电顺序错误
      • 未正确设置围栏

# 科目三：安全操作技术

# 试题： K31-01

# 考试说明

  • 考试时间：45 分
  • 分值：100 分（80 分合格）
  • 任务：10/0.4kV 变配电系统（成套开关柜）高压出线柜电缆室照明线路故障排除

# 考试内容

  1. 操作前准备与检查
    1. 完善操作票
      • 抽操作票，补齐 4 项，操作人写、监护人查，签字提交 （不合格项：填写错误）
    2. 选择工具和仪器仪表
      • 绝缘手套 （不合格项：未选 / 未穿）
      • 绝缘靴 （不合格项：未选 / 未穿）
      • 安全帽
      • 工频信号发生器
      • 高压验电器
      • 低压验电器
      • 接地线
      • 标示牌
        • 高压侧：
          • 禁止合闸、有人工作
          • 已接地
          • 止步、高压危险
          • 在此工作
        • 低压侧：
          • 已接地
          • 禁止合闸、有人工作
    3. 互检 （不合格项：任一未穿戴或未规范穿戴）
      • 安全帽
      • 工作服
      • 绝缘靴
  2. 10kV 高压开关柜停电
    1. 倒闸操作执行复诵制度：唱票 - 复诵 - 确认 - 执行
    2. 倒闸操作安全措施：
      • 核对设备名称、编号、运行状态； （不合格项）
      • 穿戴绝缘手套； （不合格项）
      • 主回路断路器按顺序操作 （不合格项）
    3. 模拟倒闸操作
    4. 倒闸操作
      1. 退出 410 电容器组
      2. 拉开 411 各出线开关
      3. 检查 411 各出线开关确已拉开
      4. 拉开 401 进线开关
      5. 检查 401 进线开关确已拉开
      6. 将 401 进线开关摇至试验位置
      7. 检查 401 进线开关在试验位置
      8. 检查 211 出线带电显示器三相灯亮
      9. 拉开 211 出线开关
      10. 检查 211 出线开关确已拉开
      11. 检查 211 出线带电显示器三相灯灭
      12. 将 211 出线开关手车摇至试验位置
      13. 检查 211 出线开关手车在试验位置
      14. 合上 211-7 接地刀闸
      15. 检查 211-7 接地刀闸确已合上
      16. 拉开 211 出线开关储能电源
      17. 拉开 211 出线开关控制电源
      18. 在 211 出线开关操作把手上悬挂 "禁止合闸、有人工作" 标示牌
      19. 在 211-7 接地刀闸操作把手上悬挂 "已接地" 标示牌
      20. 在 201 进线柜、201-41 计量柜、49PT 柜周边装设围栏，悬挂 "止步、高压危险" 标示牌
      21. 在 211 出线柜电缆室门外悬挂 "在此工作" 标示牌
      22. 在 1# 变压器低压侧验电，确认无电
      23. 在 1# 变压器低压侧挂 1# 接地线
      24. 在 401 进线开关操作把手上悬挂 "已接地" 标示牌
      25. 在 401 进线开关操作把手上悬挂 "禁止合闸、有人工作" 标示牌
  3. 高压出线柜电缆室照明线路故障排除
    1. 故障排除
      1. 高压验电器经工频信号发生器校验正常后，在高压出线柜电缆室门部位验电，确认无电 （不合格项）
      2. 确认高压出线柜电缆室照明线路故障点 - 照明灯损坏
      3. 排除照明线路故障 - 摘取 "照明等损坏" 标示牌，更换照明等
  4. 场地整理：将工具归位
